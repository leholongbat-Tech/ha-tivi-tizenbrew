# ha-tivi-tizenbrew

TizenBrew module "HA Tivi": mở dashboard Tivi của Home Assistant công ty toàn màn hình trên tivi Samsung (Tizen).

- Thêm trong TizenBrew: Module Manager → Add GitHub Module → `leholongbat-Tech/ha-tivi-tizenbrew`.
- `ha-tivi.js` (ES5) bật chế độ kiosk có sẵn của HA, giao diện tiếng Việt, nút đỏ trên remote để tải lại, tự tải lại lúc 4 giờ sáng.
- Không chứa mật khẩu hay token: đăng nhập HA một lần trên tivi.
